# Raw Data

Place the extracted CSV files from the organizer-provided Kaggle datasets in this folder.

Expected source:

- NIFTY-50 Stock Market Dataset by Rohan Rao
- Optional organizer-provided India NSE 1990-2020 dataset

The loader accepts either:

- One CSV per stock, such as `RELIANCE.csv`, `TCS.csv`, etc.
- Metadata CSV files containing company, sector, symbol, or industry fields.

Keep this folder for raw data only. Do not edit raw files directly.
